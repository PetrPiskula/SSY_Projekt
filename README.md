Tento projekt je zpracovanim Zigbee Endpointu. Jedna se o součást 4-člené sítě, která je složená spolu s ostatními studenty předmětu. 
Toto konkrétní zařízení sleduje výstup Hallovy sondy, která může být použita například jako senzor otevření okna.
Zjištěná hodnota je potom zasílána na příslušný cluster Zigbee Coordinatora, který tato data zpracovává spolu s ostatními daty z ostatních zařízení.
Hodnota je též prezentována na desce samotné pomocí onboard LED, zároveň je debug posílán na USART rozhraní, lze tak sledovat stav připojení do Zigbee sítě,
stejně jako stav měřeného senzoru.
